# Asset directory

- `png/{16,32,64,256}/` — original RGBA PNG files from the curated 126-icon pack (the default presentation files).
- `svg/vector/` — editable SVG contour traces. These are approximate, not guaranteed pixel-perfect.
- `svg/fidelity/` — SVG wrappers embedding PNG data. Visually faithful, **not** editable vector art.
- `preview/collection-126.png` — quick overview.
- `checksums.sha256` — reference hashes for immutable delivery validation.

This package does not include source-generation sheets or private drafting materials.
