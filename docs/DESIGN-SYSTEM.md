# AXR Icons — design system

- Consistent 1:1 rounded-square tile with opaque illustrated body and transparent external corners.
- A compact, distinct character per stack; intentional negative space and legible eyes and facial details.
- Never stretch individual icons to compensate for optical variance. Fix the source illustration instead.
- PNG is the current fidelity reference (not the old hand-authored draft SVGs).
- Artwork may be displayed in 16, 32, 64 or 256 px. Zooming a 16px asset to 256px is not an acceptable fidelity review.
- AI-assisted artwork must use batches of six, then pass a visual quality gate before registry update.
