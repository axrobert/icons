# Batch workflow — future additions

The base collection already contains 126 icons. Future artwork **must** be produced in batches of six, in the following sequence:

1. Select six missing technologies and define six distinct visual metaphors.
2. Generate a 3×2 comparison sheet, keeping optical scale and tile shape consistent with the existing approved collection.
3. Review the sheet before extraction.
4. Export individual PNG masters; derive 16/32/64/256 sizes.
5. Convert to genuine SVG paths separately. If tracing loses detail, prefer PNG and flag the vector for refinement.
6. Run validation and a side-by-side review at 16 and 32px.
7. Update registry and README only once that batch has passed inspection.

Retain no private draft conversation metadata in public repository history.
